## 🚀 Start here

1. Identify sensor streams, camera calibration and coordinate frames.
2. Use the sensor SDK to inspect RGB, depth and point-cloud data.
3. Validate transformations and calibration before connecting perception to manipulation.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
